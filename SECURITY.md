# Security and privacy

Never commit or share `D:\FollowupOrganizer\data`, `token.txt`, the organizer database, logs, exports, backups, diagnostics or Outlook message content. These files can contain email addresses, subjects, conversation identifiers and send history.

The local service is authenticated and binds only to loopback. Do not forward or publish port 8765. Review all recipients and messages before enabling automatic sending.

Report a suspected security issue privately to the repository owner. Do not include live mailbox data or the local token in a public issue.
